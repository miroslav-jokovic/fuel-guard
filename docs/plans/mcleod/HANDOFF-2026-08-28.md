## Traps that have each cost real time

1. **`is_void`.** Omitting it inflated settlement and deduction figures twice in one session. The
   $250 gap between a sandbox and production deduction total was one voided `TRL` row.
2. **`settled_at` is a BATCH stamp** — 3,337 June movements across 164 values. Never bucket by week.
3. **Always-zero distance columns:** `billing_loaded_distance`, `billing_empty_distance`,
   `pay_distance`, `manifest_loaded_distance`, `manifest_empty_distance`. Only `distance`,
   `move_distance` and `fuel_distance` are populated. Count rows before trusting any column.
4. **`movement_order` fans out.** Reaching a dispatcher via movements turns 1,640 June bills into
   3,408 rows and $5.49M into $11.49M. Use `orders.operations_user`, which is 1:1.
5. **Live vs `_hist`.** `UNION ALL` both, always.
6. **`tools/**` is excluded from eslint** — only `lint:agent-syntax` (added #365) parses it. A
   backtick in a SQL comment inside a template literal killed the agent at import with CI green.
