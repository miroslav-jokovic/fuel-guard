## 4. Apply migrations 0134, 0135, 0136

All additive; apply **the same way 0133 was applied** (the usual migrate workflow). Prereq:
0127–0133 already applied (they are, per HAZMATGUARD-STATUS).

- `0134_driver_app_features.sql` — the control-plane tables (RLS-on / zero-policy, no backfill).
- `0135_driver_fuel_write_closure.sql` — **security fix.** A driver JWT could insert a fuel
  transaction on any truck with any `source` (incl. `efs_feed`). No driver fuel path exists
  post-D41, so driver inserts are denied outright.
- `0136_phase9_driver_scope_closures.sql` — **security fix.** `driver_time_off` and
  `tms_movements` were readable org-wide by any driver (the 0086 ledger claimed these were closed;
  they were not). Plus a `not valid` CHECK so an ended shift must carry a reason.

0135/0136 were found by the Phase 9 release gate and are not optional — see
`RELEASE-GATE.md` § Findings.

## 9. Native build + on-device smoke (after the commit)

```bash
pnpm driver:android      # full native build — REQUIRED: three new native modules
```

Smoke, in this order (10 min):

1. **Check-in wizard**: Home → Start your day → search a unit → tap it → you MUST land on the
   trailer step (the reported bug); pick trailer/bobtail → confirm → start. Try a search with no
   matches → empty state, never a blank list.
2. **Feature flip**: web → Settings → Driver App → toggle "Driver score" off → pull-refresh Home
   in the app → Score tab + tiles gone together. Toggle back.
3. **Hazmat**: More → Hazmat checks (needs the org's `hazmatguard` entitlement granted in
   apps/admin, and the test driver's certifications entered in web → Compliance) → capture →
   verdict → reopen from history.
4. **Notifications**: bell on Home → centre opens; mute a category; from the web release/cancel a
   test hazmat submit → row appears in the centre (push buzz only after the DSN/EAS steps below).
5. **Messages** (needs the `messages` entitlement): app → Home mail icon → "Message dispatch" →
   send; web → Messages → reply → appears in the app (realtime) → long-press the received
   message → report flow.
6. **End shift + stop capture**: primary buttons are pinned at the bottom, no scrolling needed.
