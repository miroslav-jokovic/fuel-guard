Small-screen redesign — four directions

Drawn with the product's own type, colours and badges, using the figures staging showed on 11/14. Nothing here is built. Each frame is the exact width named under it.

A · The record card (every table below tablet width)

Today a row becomes an unbordered block inside one long white slab, with every column given equal weight. The proposal: each row is its own card with a fixed anatomy — who it is, one line of context, three figures, and the rest folded away.

Rules behind A

  • Card = 1px edge, 12px radius, 8px gap. Never a divided slab.
  • Line 1: name + status + ⋮. One line, truncates.
  • Line 2: one context sentence, muted.
  • Exactly 3 figures in a fixed 3-column grid — never a wrapping row with an orphan.
  • Everything else behind "details", label column fixed at 116px so values line up.
  • Every touch target ≥ 44px; buttons never wrap (overflow goes to ⋯).
  • Dates in MM/DD/YYYY as everywhere else.

B · Charts and dashboard cards (Fleet overview)

Today chart cards are sized by the window, so at 1024px with the sidebar open the Fleet MPG card is about 210px wide: its description breaks one word per line and its link prints over its title. On a phone the page is 541px wide inside a 390px screen. The proposal: a card decides its layout from its own width, a chart never drops below 300px wide, and an empty chart says so instead of drawing empty axes.

Empty and narrow states. No data = one sentence, not a blank grid 250px tall. A title that shares its row with a switch ("Where open cases concentrate" + Vehicles/Drivers) is shortened and the switch drops to its own full-width row.

Rules behind B

  • Layout follows the card's own width (container queries), not the window.
  • Chart minimum 300px wide × 190px tall. A grid cell that cannot give that becomes full width.
  • X axis: at most 4–5 labels, thinned automatically.
  • Card title: one line, never wraps. Description: 2 lines max.
  • Card link lives in the footer below 22rem of card width.
  • Nothing may be wider than the screen: the hidden data table behind each chart is clipped (that is the 541px today).

C · Operations tab

Today: nine equal cards holding 37 rows, of which 28 read "0" on staging, each row repeating a label, a sentence, a number and a link. Cards in one row are stretched to the tallest, leaving half-empty boxes; on a phone the tab is 4,454px long. The proposal keeps every figure but orders the page by what needs a person: the fleet's state, then what needs action, then each area — with quiet rows made quiet.
