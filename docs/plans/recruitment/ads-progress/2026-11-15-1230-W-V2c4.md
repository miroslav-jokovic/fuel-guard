**2026-11-15 · Track W · V2c-4 — no ads agent is sent a lead's name, phone or e-mail (Q-APX2)**

The owner accepted Fable 5.2's 30-day retention (Q-APX2, ruled (a), 2026-11-14) on one condition: no ads agent
is ever sent a lead's contact details. That condition is now a test
(`security/adsAgentInputBoundary.test.ts`), so it stays true as agents are added.

**It is structural, and that is a limit worth stating.** A phone number and an e-mail have a shape; a name does
not — no check of a request's text can tell an applicant's name from a carrier's. So the rule is held where it
can be held exactly:

1. Every Claude agent's real request, built by its own builder over every one of its fixtures, names no
   contact field and holds nothing shaped like a phone or an e-mail. The agent list is typed, so a new agent
   without its builder under the test does not compile.
2. The code that builds agent inputs (`workers/`, `compose/`, `generations/`, `plan/`) imports nothing from
   lead intake and names neither the lead contract, the leads table nor a contact column.
3. What recruiting hands across — a lead's outcome and the lead-quality counts — carries ids, stages and
   counts only; a row with a name on it does not parse.

**No runtime refusal at the rail, on purpose.** It could only match shapes, so it would stop an ad over the
carrier's own office number and still let a name through.

**One thing the test found on its first run.** The Analyst's scheduler imported a helper from the lead-intake
folder. The helper reads connection ids and nothing of a lead ("for each Meta connection, queue a job"); it had
simply been written beside the first scheduler that needed it, and three others borrowed it from there. It moved
to `connections/connectionsTick.ts` and all four schedulers import it from there — the file was not exempted.

Mutants: 8 planted one at a time, each making a builder reach a lead or send a contact field (a contact key on
the Strategist's sheet, a phone on it, an e-mail key and an e-mail value on the Analyst's sheet, an import from
lead intake, the leads table named, the lead contract named, a phone in an evidence sentence): 8 caught.
