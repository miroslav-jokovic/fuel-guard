**2026-11-19 · Track W · V5 part 1: one table of who acts (Q-APX21 (a), Q-APX22 (a))**

- **Why first.** Read on 2026-11-19: `ADS_AUTHORITY` was read by nothing but its own test, and the machine, the doors
  and the guard each said who acts on their own. A table of modes on top would have been a third statement.
- **The table now holds every act the code performs.** Added: `start_campaign`, `write_plan`, `approve_plan`,
  `regenerate` (the campaign's move, a person's; `regenerate_once` stays compose's own retry), `resume_after_failure`,
  `record_outcome`, `retire_tired_ad`, `turn_on_approved_replacement` (the agent's, Q-APX22).
- **The machine answers to it.** `CAMPAIGN_EVENT_ACT` binds each of the machine's 26 events to an act (or names it a
  platform fact); the test "the machine lets nobody act whom the authority table forbids" fails on any row whose
  actors the table does not allow. `kill` is bound to `pause`, the move it makes (the switch is `kill_switch_on`).
- **The four acts outside the machine ask at their door:** `createCampaign` and `decideOnCreative` refuse 403
  `not_permitted`; `retireTiredAds` records `acted: "not_permitted"` and calls nothing; `turnOn` publishes nothing.
  Each door has a test that changes the table in-process (`testing/withAuthority.ts`) and sees the door follow it.
- **The steps** (`AD_STEPS`): start a campaign (Manual), approve the plan (Assisted), approve an ad (Assisted;
  Autopilot locked, Level C), launch (Assisted; Autopilot locked, Level B), replace a tired ad (Manual or Assisted,
  read from `creative_refresh.retire`). A mode is locked because the table gives its acts to no agent — the test
  "a locked mode is locked by the authority table, not by its words" holds the words to the table.
- **Also fixed:** `retireTired.ts` still said "a person acts until Q-AD68 is built"; Q-AD68 was built on 11-11.
- Mutations, each alone, each red (8): each of the four door checks removed; the machine letting the agent launch;
  the table giving the agent ad approval (opens Level C — two tests); `kill` bound to the switch act; the tired-ad
  mode hard-coded.
