**2026-11-15 · Track W · V2c-3 — the doors where a person reads, edits and approves a plan**

Built:

- **Three routes** (`routes/plans.ts`, doors in `plan/planDoors.ts`):
  - `GET  /api/ads/campaigns/:id/plan` — the newest version with its evidence. View access, like the campaign.
  - `POST /api/ads/campaigns/:id/plan/versions` — a person's edit, saved as the next version. Manage access.
  - `POST /api/ads/campaigns/:id/plan/approval` — approve a version by id; the campaign moves to composing with
    that plan named on it (`plan_approved`, the event the general moves door excludes). Manage access.
- **A person approves only the newest version.** If somebody saved an edit while another person still had the
  earlier version open, that second person's Approve is answered "the plan changed, reload" — otherwise the
  campaign would compose from the older version and the edit would be silently dropped.
- **An edit is open only while the plan waits for review.** The machine has no say over an edit (it moves no
  state), so the door asks itself.
- **A refused edit says why, in sentences** (`planFindingWords`, shared): the same sentences the Strategist is
  shown on its second ask. One definition; the worker's own copy was removed.
- The read answers a view with no author id and no generation id — a name and "agent or person" is what the
  screen needs.
- Both security tests hold the new routes: the gate ledger names each route's gate, and the sweep calls all
  three with a second carrier's plan in the database and shows only ours comes back.

**No host plans yet, still.** With the doors in place a campaign in `plan_review` now has a way out through the
API, but not through the screen. `CampaignWorkers.plan` is filled in the step that also hands recruiting's lead
counts to the planning step and puts the Strategist on the list of workers a launch waits for — after the plan
review screen, so no campaign reaches a state the office cannot act on from the page.

Not built: `workers.plan`, the contact-field boundary test (Q-APX2), the plan review screen, producers reading
the plan's angles.
