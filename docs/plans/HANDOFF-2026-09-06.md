## 3. Traps and findings — the part a fresh chat would waste a day rediscovering

### 3.1 The reusable finding: a fact stated twice will drift, and the second copy fails silently

Three defects this session were the same shape, and all three failed quietly rather than loudly.

- **#610** — the settings read had a hand-written column list; C8 added three form fields and the list
  did not gain them. `saveRouteFuelSettings` upserts the WHOLE form, so a Save would have written
  nulls over targets set an hour earlier, with blank fields on screen that looked like the truth. The
  list is derived from `routeFuelSettingsFormSchema` now.
- **#596** — a scheduler's 24-hour `setInterval` in a service that redeploys 8–42 times a day. The
  interval said "daily" and the process said otherwise; the marker is persisted now.
- **#604** — ten test suites set `EFS_SOAP_MAX_RPS: 100` meaning "do not pace me". `soapLaneRps` never
  consults that knob for the interactive lane, which defaults to **1 rps**.

**When you add a field, grep for every place that names the OTHER fields beside it.** A select list, a
form schema, a default map and a UI are four places, and only the compiler sees two of them.

### 3.2 Gates — every one that fired this session was right

`lint:table-writers` refused a cross-module write twice (route it through the owner —
`markFuelSweepComplete`, `assignAnomalies`). `lint:boundaries` refused `admin.from(table)` over a
dynamic name — invisible to every table gate. `auditEntityId` refused a comma-joined id list in a uuid
column. `lint:filesize` refused `DashboardPage.vue` at 517 lines, and the split was right for a reason
the gate cannot know: that page is deliberately untested at component level, so permission logic must
not live in it. **CI refused a test that read source with `node:fs` — `packages/shared` has no Node
types on purpose, it builds for React Native.**

### 3.3 Two dynamically-gated routes need TWO ledger entries

`GET /api/fueling/findings`, `/findings/summary` and `POST /findings/assign` are gated per ROW, not per
mount — a static `requireSection` could only name one of the two sections they serve. Each needs an
entry in **`OPEN_ROUTES` (`testing/routeLedger.ts`)** *and* in **`GATE_WAIVERS` (`routeGates.test.ts`)**,
each with a written argument. Missing either fails a different test.

### 3.4 Mutation testing found two of my own tests that proved nothing

`not.toContain("$0.00")` where `usd` emits `$0`; and a source-assertion whose fixture's only row
already had the value being asserted. **A fixture too uniform to discriminate is the failure mode** —
see `[[prove-tests-fail-by-mutating]]`. Both were caught by mutating the subject, neither by review.

## 6. ⚠ The `pnpm test` flake is NOT fixed, and #604 was a different bug

`pnpm test` (all packages + matrices) fails roughly **one run in three or four**, never in isolation.
`apps/api` alone passes repeatedly, and **CI has never shown it** — `test-api` is its own job there,
which fits contention being the trigger.

**#604 fixed a real problem that was not this one.** Captured evidence, which differs from the
transport fault already documented in `apps/api/src/testing/httpServer.ts` (that note says explicitly
*"no assertion mismatch anywhere in the captured run"*):

```
fuelCardsControl.test.ts > requires an expectedVersion on every write
  AssertionError: expected 404 to be 400
```

**404 where 400 is expected means the route never matched** — validation never ran. Leading hypothesis:
**port reuse.** 43 api suites call `app.listen(0)`, and a pooled undici socket for `127.0.0.1:<port>`
can outlive the server that owned it, so a later request reaches a different app with no such route.
Untested. To reproduce: loop `pnpm test`, redirect to a file, grep for `AssertionError`.

## 8. Method, which is not negotiable

Every claim in this file was measured. Every test added this session was **proved able to fail by
mutating its subject**, and two that could not were fixed rather than kept. One step per PR; a column
and its first reader ship in two merges; every gate run individually before a push. When a gate
refuses something, it was right five times out of five this session — read its message before
reaching for a waiver.
