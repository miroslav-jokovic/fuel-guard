## 3. What M2 actually shipped

- **`invites.driver_id` (0102)** carries "invite THIS roster row" through the email round-trip.
- **`POST /accept`** (`routes/invites.ts`) now, when `driver_id` is present: loads the driver → 404 if gone → **409 if already linked to a different account** → sets `user_id` + `app_access_enabled`. Runs _before_ the invite is marked accepted, so a failure leaves it pending and retryable. Generic office invites (`driver_id` null) are untouched.
- **`/api/roster/drivers`** — `GET /` (list), `POST /` (create, always `identity_source='manual'`), `POST /:id/invite` (enroll). Read gate = `rolesThatCanView('fleet')`; write gate = `rolesThatManage('fleet')`; **enrollment is narrower — admin + fleet_manager only**, because it hands out a login. `routeAuth.test.ts` picked up the new mount automatically.
- **`rosterContract.ts`** — reuses `DRIVER_STATUSES` (constants) and `DRIVER_TYPES` (loadsLifecycle) rather than redeclaring them. `deriveFullName()` is pure and unit-tested; `full_name` stays canonical and NOT NULL.

## 5. Delivery mechanism (this session's lesson)

The desktop bridge was **online**, so files went straight into the working tree with `device_commit_files` and every checksum was verified against the cloud clone. Prefer this over git bundles — a bundle only counts once `git fetch` + `git merge` has actually run on the Mac.

Bridge caveats: it **cannot unlink files**, so `git` run _through the bridge_ leaves a `.git/index.lock` it can't clean up (moved to `_to_delete/`). Run all git in your own Terminal.

## 7. Verified gotchas (don't relearn these)

- `packages/shared` resolves from `src` for api/tsx, but the **driver app consumes `dist`** — driver tests fail with `Cannot find package '@fuelguard/shared'` until `pnpm --filter @fuelguard/driver shared` builds it.
- `create policy` has no `if not exists` — every policy here is `drop policy if exists` + `create`, same for triggers. That is what makes 0097–0102 re-runnable.
- A concatenated select-column string (`"a, b" + "c"`) widens to `string` and collapses PostgREST's row type to an error union. Keep column lists as ONE literal.
- API conventions: router factory + `router.use(requireAuth)`; per-route `requireOrg, requireRole(...), [validateBody], asyncHandler`; `orgId = req.auth!.orgId!`; mount as a single line `app.use("/api/x", xRouter())`. `validateBody` returns **400**, `requireOrg` returns **403**.
- No test mocks Supabase — route tests assert gating only; DB logic goes in pure service unit tests.
